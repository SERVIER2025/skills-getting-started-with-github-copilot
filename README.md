## Redis Docker 镜像

本仓库提供了一键拉取 Redis Docker 镜像的脚本与文档：

- 📄 [拉取说明文档](docs/redis-docker.md)
- 🐚 [pull-redis.sh 脚本](scripts/pull-redis.sh)

```bash
# 快速拉取最新版 Redis
chmod +x scripts/pull-redis.sh
./scripts/pull-redis.sh

# 拉取指定版本，例如 7.2-alpine
./scripts/pull-redis.sh 7.2-alpine
```
